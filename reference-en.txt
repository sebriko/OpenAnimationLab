# Open Animation Lab – quick reference for AI assistants

Version 4.4.0

All commands of the Open Animation Lab (OAL) in short form. The OAL is a free JavaScript editor in the browser: https://www.educational-animation.org/oal/ – full reference: https://www.educational-animation.org/en/editor-reference/

Only use commands listed here. Classes are written without a namespace: new Rectangle(…), new Text(…).

## Rules

- Every animation starts with `let board = new Board(1280, 720);`. Coordinates in pixels, (0 | 0) is top left, y grows downwards. Angles in degrees, positive rotation is clockwise.
- Reference points: Rectangle = top-left corner; Circle, Ellipse, Polygon, Arc = centre; Line, Arrow, LinePath = the given points.
- Graphics stack in the order they are created. UI components (Text, Button, ButtonSlider, Checkbox, RadioButton, NumericStepper, Dropdown, MathForm, ParameterTable, Model3D, HtmlRectangle, PlayButton) always lie above all graphics, cannot be rotated and cannot be put into a Group.
- Text: (x, y) is the top-left corner of a box with 10 px padding. Formatting: <b>, <i>, <sub>, <sup>, colour with <span style="color:#c0392b">…</span>. Line break with \n or <br>.
- No backslashes except \n (they are doubled before the code runs). Write special characters directly. In MathForm (LaTeX) use a single backslash.
- Blocked, also as names: window, document, fetch, eval, globalThis. Never name your own variables like classes (Line, Text, Group, Timer …).
- Events: sliders, Checkbox, RadioButton, NumericStepper and PlayButton report changes with onChange(e => …), the new value is e.value. setValue() does not fire onChange. Mouse anywhere on the board: board.onMouseMove(e => …) with e.x and e.y; keyboard: board.onKeyDown(e => …) with e.key.
- Motion: `let timer = new Timer(); timer.onUpdate(() => { … }); timer.start();` – without a duration the timer runs endlessly, timer.getElapsedTime() gives the time in ms.
- Numbers: Calc.format(number, digits, "unit"). Sliders and number fields show a decimal point in English and a comma in German animations automatically.
- Write `// lang: en` or `// lang: de` in the first line.

## For almost all graphics

Properties x, y, rotation, visible. Methods: setAlpha(0.5), setScale(1.5, 1.5), setRotationPoint(x, y), onClick(f), onMouseDown(f), onMouseUp(f), onMouseOver(f), onMouseOut(f), setDragging(x1, y1, x2, y2), onDragStart(f), onDrag(f), onDragEnd(f). UI components have x, y, visible and setTooltip("…").

## Graphics

### Board – Drawing area for the animation (Board – SVG renderer)
`let board = new Board(1280, 720, 0xFFFFFF);`
Parameters: width (Logical width of the board in pixels); height (Logical height of the board in pixels); backgroundColor (Background color in hex format (e.g. 0xFFFFFF))
Properties: backgroundColor (Background color of the board in hexadecimal format)
Methods:
- `board.addChild(myElement)` – Adds an SvgJSEdu element to the board
- `board.removeChild(myElement)` – Removes an element from the board
- `board.setFramerate(30)` – Sets the animation framerate (for ticker-based animations)
- `board.onMouseDown(e => console.log(e.x, e.y))` – Calls the function when pressing the mouse anywhere on the board. It receives e with e.x and e.y (position on the board in pixels)
- `board.onMouseUp(e => console.log(e.x, e.y))` – Calls the function when releasing the mouse anywhere on the board. It receives e with e.x and e.y (position on the board in pixels)
- `board.onMouseMove(e => console.log(e.x, e.y))` – Calls the function when moving the mouse anywhere on the board. It receives e with e.x and e.y (position on the board in pixels)
- `board.onKeyDown(handler)` – Registers a keyboard key-down handler. The callback receives a safe event object with key, code, repeat, ctrlKey, shiftKey, altKey, metaKey.
- `board.onKeyUp(handler)` – Registers a keyboard key-up handler. The callback receives a safe event object with key, code, repeat, ctrlKey, shiftKey, altKey, metaKey.
- `board.isKeyDown('ArrowUp')` – Returns true if the specified key is currently pressed
- `board.getKeysPressed()` – Returns an object with all currently pressed keys

### Group – Group for combining objects
`let myGroup = new Group();`
Properties: x; y; rotation; visible
Methods:
- `obj.addChild(myRectangle)` – Adds an element to the group
- `obj.removeChild(myRectangle)` – Detaches an element from the group. It stays visible on the board; to remove it completely use board.removeChild(element)
- `obj.getBounds()` – Returns the bounding box of the group
- `obj.setMask(10, 20, 100, 80)` – Sets a rectangular mask for the group
- `obj.removeMask()` – Removes the mask from the group

- `obj.setGradient("linear", [{offset:0,color:"#fff"},{offset:1,color:"#000"}])` – Creates a linear or radial colour gradient. Parameters: type (linear or radial), a list of colour stops, each with offset (0 to 1) and color (#hex), optional angle in degrees for linear gradients

### LinePath – Line path from points
`let myLinePath = new LinePath([[0,0], [100,50], [200,100]], 0xff0000, 3);`
Parameters: points (Array of coordinate pairs [[x1,y1], [x2,y2], ...] in pixels); color (Line color in hexadecimal format (e.g. 0xff0000)); thickness (Line thickness in pixels)
Properties: x; y; visible
Methods:
- `obj.setFillColor(0xff0000)` – Sets the fill color of the shape
- `obj.setPoints([[0,0], [100,50], [200,100]])` – Replaces the entire point array. If the path was closed, it will be automatically closed again.
- `obj.addPointEnd(150, 75)` – Adds a point at the end of the line
- `obj.addPointStart(25, 25)` – Adds a point at the beginning of the line
- `obj.removePointEnd()` – Removes the last point of the line
- `obj.removePointStart()` – Removes the first point of the line
- `obj.shiftX(50)` – Shifts the entire line by a delta value in X direction
- `obj.closePath()` – Closes the path by connecting the first and last point. The path remains closed after setPoints() calls.
- `obj.openPath()` – Opens a closed path by removing the closing point and disabling auto-close.
- `obj.setColor(0x00ff00)` – Sets the line color
- `obj.setThickness(5)` – Sets the line thickness
- `obj.markAt(100, 0xff0000, 5)` – Marks a point on the path at given x-coordinate
- `obj.removeMark()` – Removes the marker from the path

### BezierPath – Bezier curve with control points

Properties: visible; x; y
Methods:
- `obj.setFillColor(0xff0000)` – Sets the fill color for closed bezier shapes
- `obj.setPoints([[0,0,10,-10], [100,50,120,30], [200,100,180,120]])` – Replaces the entire point array with a new array
- `obj.addPointEnd(150, 75, 160, 60)` – Adds a point with control point at the end of the bezier path
- `obj.addPointStart(25, 25, 30, 20)` – Adds a point with control point at the beginning of the bezier path
- `obj.removePointEnd()` – Removes the last point of the bezier path
- `obj.removePointStart()` – Removes the first point of the bezier path
- `obj.shiftX(50)` – Shifts the entire bezier path by a delta value in X direction
- `obj.setColor(0x00ff00)` – Sets the line color
- `obj.setThickness(5)` – Sets the line thickness
- `obj.getY(100)` – Returns the y-coordinate for a given x-coordinate on the curve
- `obj.getX(150)` – Returns the x-coordinate for a given y-coordinate on the curve

### Arc – Circular arc around the origin (centre). With a fill colour a pie slice, with an inner radius a ring segment, with an arrowhead a rotation arrow. Angles in degrees: 0 = right, positive angles clockwise
`let myArc = new Arc(80, -90, 90, 0x444444, 3);`
Parameters: radius (Radius in pixels); startAngle (Start angle in degrees (0 = right, 90 = down)); endAngle (End angle in degrees. Larger than the start angle = clockwise, smaller = anticlockwise); lineColor (Line colour in hexadecimal format (e.g. 0x444444)); lineThickness (Line thickness in pixels (0 = no line))
Properties: x; y; rotation; visible; alpha
Methods:
- `obj.setAngles(0, 270)` – Sets start and end angle in degrees
- `obj.setStartAngle(-90)` – Sets the start angle in degrees
- `obj.setEndAngle(180)` – Sets the end angle in degrees
- `obj.setRadius(100)` – Sets the radius in pixels
- `obj.setInnerRadius(60)` – Inner radius in pixels: turns a pie slice into a ring segment (0 = pie slice)

- `obj.setCoils(12)` – Sets the number of coils

- `obj.setLineColor(0x2e86c1)` – Sets the line colour

- `obj.getLength()` – Returns the distance between start and end point in pixels
